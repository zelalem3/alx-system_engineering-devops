# ALX System Engineering & DevOps

A collection of exercises and projects completed while studying system engineering and DevOps with ALX. The repository covers Linux, shell scripting, networking, web infrastructure, configuration management, and debugging.

## Topics

- Shell basics, permissions, redirections, variables, loops, and processes
- Networking fundamentals, SSH, and HTTPS
- Web servers, load balancing, and application servers
- Configuration management and web-stack debugging
- API usage, MySQL, firewalls, and incident postmortems

## Repository structure

Projects are organized in numbered directories. Each directory contains exercises for a particular topic; see its files and any project-specific instructions for details.

## Requirements

Requirements vary by project. Exercises may use Bash, Python, Puppet, or common Linux networking and server tools. Check the relevant project directory before running a script or command.

## Usage

```bash
cd 0x00-shell_basics
```

Review the files in the chosen directory and run commands only in an environment where you understand their effects. Some exercises modify system or server configuration.

## Note

This repository is a record of learning exercises. The code and configurations are educational and may need review before use outside a coursework environment.
